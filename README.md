# NUCMA

> 面向校园、青年组织与公共服务门户的多风格 Halo 主题，提供专题化内容模板、成员与友链展示、中英双语界面和完整的响应式阅读体验。

当前版本 **0.0.5**（Halo `>= 2.27.0`）。变更见 [CHANGELOG.md](CHANGELOG.md)，版本号规则见工作区根 `docs/versioning.md`（跨仓文档，不随本仓发布）。

版本号规则：**大**（体系级变化，升 `MINOR`，如 0.0.x → 0.1.0）、**中 / 小**（升 `PATCH`）。已发布 tag 不删不重打。

NUCMA 的产品定位是校园、青年组织与公共服务门户。它适合校园门户、学生组织、协会、公益项目、社会实践团队和内容型机构站点：首页便于发布公告与动态，分类和文章模板可以承载专题报道，成员与友情链接则通过 Halo 插件的公开能力按需接入。

## 核心能力

### 页面与阅读体验

- 首页区块可排序，可组合文章、成员公示与友情链接；文章区块支持全部文章或 1 至 3 个分类栏。
- 首页文章支持卡片网格，可选编辑部卡片 / 大图叠字 / 剪贴簿 / 便当格等卡片样式，并可设每行列数与标题最多行数（默认「不限」，选具体行数才裁切）；首页不再输出列表分页，「更多」统一跳转归档页，归档页采用门户条目流卡片。
- 站内链接跟随站点自定义路由：归档、分类、标签入口统一取 `site.routes`（如站点把归档改成 `/a`、分类改成 `/c`，页脚导航与「更多」按钮会自动跟随），不再写死 `/archives`。
- 页头独立于首屏、在所有页面统一使用一套：首页同样渲染站点头部，明暗切换、搜索与登录入口都在页头里；搜索点开的是主题自带弹层，结果分「文章 / 页面 / 成员 / 友情链接」四组、顶部 chips 带计数，成员命中可直接跳工牌；首屏高度按 `100svh` 减去页头高度计算，页头加首屏刚好一屏。
- 十一套首屏版式都做了深色适配：背景、标题、正文、玻璃卡片、便签卡随主题切换；归档页门户流在深色下悬停改为二级底色，不再变白。
- 提供归档、分类、标签、友链、成员、关于页、文档、瞬间、图库和错误页等页面样式。
- 文章页提供侧边栏、阅读量、标签、评论区和自动目录等可配置能力；标题下有署名行，可全站统一署名（或单篇用自定义元数据 `nucma.cn/author` 覆盖），正文末尾连续的「【拍摄: …】」段落会自动收成一块版权页式署名区。
- 文章页支持公众号式划线：选中正文浮出「划线 / 取消划线 / 分享」小工具条，划线记录只存在读者自己的浏览器里，「分享」可生成带二维码的分享长图（图片在浏览器本地合成，不经过服务器）。
- 正文图片自动整理：同一个 figure 里的多张图、后台连续插入的两张横图会并排成图组（各带图注，手机改上下排列）；比版心窄的低清图最多放大到原图的 1.25 倍，不再拉满整栏。
- 文章阅读时显示顶部进度；桌面端使用侧栏目录，移动端使用目录抽屉，并提供分享、复制链接和回到顶部操作，标准文章与专题文章均可自动提取标题。
- 正文大图支持无依赖预览，可用键盘切换、滚轮或按钮缩放、拖动查看，并自动忽略链接图片、表情和小图标。
- 文章封面和列表图片使用稳定尺寸与异步解码；列表与内容图只需写 `sizes`，由 Halo 按缩略图补 `?width=` 多档 `srcset`，不手写 `srcset`。
- 友链页支持按名称、简介或网址实时搜索，结果数量和分组数量会随筛选同步更新。
- 支持浅色、深色和跟随系统模式，统一明暗切换和滚动动画节奏。
- 桌面、平板与手机使用同一套响应式布局；手机端使用带动画的汉堡导航，并将 Halo 菜单与页头自定义链接分区显示。
- 关于页支持正文、统计、最新内容、分类、发展历程、服务入口、项目展示、成员、友链和常见问题自由排序，适配组织介绍、公共服务和专题项目展示场景。

### 成员页与关系网

- 成员卡片展示头像、学校、分组与认证状态，支持详情预览、键盘操作与 Esc 关闭；未完善资料的成员默认显示其 QQ 头像。
- 搜索支持空格分隔的多关键词、拼音与首字母，以及 `学校:`、`分组:`、`地区:`、`qq:` 字段前缀。
- 概览条汇总成员总数、分组数、学校数、近 30 天新增，地区分布、最近加入与省份地图默认收起。
- 「网格 / 关系网」可切换：关系网把头像铺在球面上，可拖动旋转、方向键微调、悬停显示姓名，点击头像打开详情；可显示学校关联连线，并配置连线阈值与「分析依据」面板；开启「减少动态效果」时停止自转。
- 关系网进入即全屏沉浸（深空背景 + 星点），明暗切换不会退出全屏；点开某位成员后左上浮出关系面板，关联成员全部列出，超出面板高度时自动缓慢滚动（悬停暂停，减少动态效果时改为面板内滚动），底部「查看全部关系」可在星图下方展开通栏清单。
- 「补全 QQ 链接」与认领页共用一套资料编辑：默认 QQ 头像、头像上传（浏览器内裁方形并压到 96KB 内）、学校与地区联动。

### 错误页与登录注册页

| 页面 | 能力 | 后台开关 |
| --- | --- | --- |
| 404 / 4xx / 500 / 5xx | 页面风格、标题与高亮词、状态标签、说明、按钮、插图、入场动画、织带颜色；成员工牌可按分组或指定名单取人，支持随机换人、点击翻面看 QQ 加好友链接与二维码 | 「404 页面」设置组 |
| 登录 / 注册 / 找回密码 / 退出 | 固定的「深红品牌面板 + 表单卡片」分栏版式，面板里只有一句大字标语；站名、Logo、主色分别读站点的站点名称、站点 Logo 与品牌主色；页面标题与引导语走内置文案；始终提供「返回首页」、始终跟随站点明暗，登录注册互相跳转 | 「系统页面 · 登录注册页」只有「启用登录页美化」一个开关 |

错误页统一输出 `robots=noindex, nofollow`；登录注册页在关闭美化后回落到 Halo 默认页。工牌取不到成员时回落到主题内置示例数据，页面不会空白。

登录注册页刻意不做站点级自定义：只保留一个美化开关，其余全部沿用站点已设置的数据，改站点名称、Logo 或主色时登录页会自动跟着变，不必再单独维护一份。站点副标题不参与渲染——实测它常与标语同义，排两遍反而重复。

### 专题模板

分类与文章都可以在 Halo 编辑器中选择模板，无需复制页面或修改主题文件。

| 类型 | 可选模板 |
| --- | --- |
| 页面 | 关于页、认领页 |
| 分类 | 知识库列表、网格卡片、红色革命、绿色环保、蓝色马卡龙、三下乡、校园节庆、科技未来、公益志愿、传统文化、体育赛事 |
| 文章 | 信件 / 公告、杂志大图、权威发布、专题报道、沉浸阅读、人物对谈、实践手记、数据纪实、影像叙事、行动倡议 |

其中，“三下乡专题”和“实践手记”适合社会实践队伍、服务基层记录和成果报道；“信件 / 公告”模板不会自动首行缩进，适合公开信、通知和正式文稿。

### 视觉风格

主题固定使用「标准门户」这一套视觉语言：紧凑页头、居中机构首屏、矩形信息卡片与统一的门户信息密度，不再提供多风格切换。用户仍可设置自定义主色；专题分类和专题文章拥有独立视觉表达，不会被站点主视觉抹平。页脚另有「默认 / 12 号 · 品牌水印 / 33 号」三套样式，随明暗模式一起切换。

### 组件设计系统

主题使用 Tailwind CSS 4 与 DaisyUI 5 作为本地构建的组件基础，不依赖公共 CDN：

- DaisyUI 统一按钮、输入框、徽章、状态提示、卡片、菜单和图片预览工具等组件状态。
- NUCMA 自有样式继续控制门户布局、内容密度与专题模板，不直接套用默认演示主题。
- DaisyUI 的颜色、圆角、边框和明暗变量映射到主题设置与自定义主色，改主色时组件会同步变化。
- 阴影使用低、中、高三档语义层级，只表达卡片悬停、浮层和模态框的空间关系，避免全站浮卡化。
- Tailwind 与 DaisyUI 仅参与构建，最终访问站点时不需要 Node.js，也不会请求外部样式资源。

### 资源与性能

- 显示字体「快看世界体」（`KuaiKanShiJieTi.woff2`，约 728KB）不做全站 `preload`，由 `@font-face` 配合 `font-display: swap` 按需加载：页面真正渲染该字体时才下载，避免每页白耗带宽，也不会触发浏览器「预加载但未使用」的提示。
- 样式与脚本全部本地构建、带版本查询串（`?v=<主题版本>-<资源指纹>`），升级主题时浏览器自动换新缓存，不依赖公共 CDN。

### 多语言

- 界面文案以 `i18n/default.properties`（简体中文）与 `i18n/en.properties`（英文）为唯一来源，各 692 键，键集合必须一致。
- 模板里用 `#{key}` 或 `#messages.msg('key')`，前端脚本里用 `t('key')`；`templates/modules/i18n-dict.html` 由 `npm run i18n` 生成，不手改。
- 页面语言随 Halo 的站点语言设置（`#locale`）切换，`<html lang>` 同步输出。
- 新增或删除文案键后必须重跑 `npm run i18n`，否则 `npm run check` 会拦下。

## 后台配置

主题设置按「先看长相 → 再看首页 → 然后每类页面 → 最后才碰代码」的顺序分成 10 个区域，后台里就按这个顺序排列：

| 区域 | 管什么 |
| --- | --- |
| 全站外观 | 默认明暗模式、自定义主色、日期格式、全站承接背景与底色；末尾三项是高级项：开发者诊断模式、自定义 CSS / JS |
| 首页首屏 | 首屏版式，以及**当前版式会用到**的字段：主副标题、简介、小字、按钮、首屏数字、三块内容、成员名单、封面底图、旧版横幅背景。切换版式时只显示这个版式需要的选项 |
| 首页区块 | 首屏之下的区块顺序与内容：文章区块（显示数量 / 行数 / 显示样式 / 卡片样式 / 标题行数 / 每行列数 / 分类栏；后几项按所选样式条件显示）、成员公示、友情链接 |
| 页头与导航 | 所有页面共用的页头（含首页）：Logo、站名、菜单对齐、顶部菜单、登录入口、搜索、明暗切换、链接轮播 |
| 页脚 | 页脚样式（默认 / 12 号品牌水印 / 33 号卡片漂浮）、菜单栏目、「加入我们」、标语、版权、自定义栏目、ICP 与公安备案；各栏按栏目数等宽均分 |
| 文章页与侧边栏 | 侧栏菜单、阅读量、封面、标签、自动目录、评论区、侧栏区块顺序；发布日期精度（年月日 / 年月 / 仅年份）、文章署名文字与文末署名标题、允许划线与划线样式、连续图片自动并排 |
| 关于页 | 区块排序、统计数据、发展历程、服务入口、项目展示、常见问题 |
| 成员页与独立页面 | 成员页概览、地图审图号、成员页评论区、默认视图与关系网连线；普通单页与友链页的评论区 |
| 系统页面（404 / 登录注册） | 404 的页面风格、文案、按钮、成员工牌、插图、入场动画与织带颜色；登录注册页只有一个「启用登录页美化」开关（其余读站点数据） |
| SEO 与分享 | 输出 canonical 与社交分享标签、输出页面结构化数据；文章页额外输出 `meta author`、`meta keywords`、Open Graph `article:*` 与 JSON-LD Article（含作者、栏目、标签、发布与修改时间），成员页与友链页按成员/站点逐条输出结构化数据；全站声明 `applicable-device` 与 RSS 订阅地址 |

三处容易找错位置的地方：

- **页头在所有页面统一使用一套（含首页）**。首屏不再自带页头；Logo、站名、导航、登录 / 搜索 / 明暗切换都在「页头与导航」配置，页脚品牌与页头 Logo 落在同一条外框线上。
- **首屏和它下面的区块是两组**。「首页首屏」只管顶部那一段（满屏）；首屏之下的文章 / 成员 / 友链区块在「首页区块」，拖动排序、设置数量都在那里。
- **成员工牌横跨两页，设置只有一份**。工牌的风格、成员来源、名单、入场动画与织带颜色在「系统页面」，404 与成员页共用同一份配置。

设置项跟着你选的样式走，不会一股脑全铺在页面上：

- **首屏 15 种版式**：选哪个版式才出现哪个版式用得上的项。选 15 号（不显示首屏）后整组只剩「首屏版式」一个下拉。
- **页脚 3 种样式**：「加入我们」链接 / 文字 / 样式 / 图标与页脚标语只在 12 号、33 号出现；页脚菜单栏目与自定义栏目只在默认与 12 号出现。
- **404 两种风格**：选「简洁版」后其余设置全部隐藏——简洁版是固定版式，不读任何设置。
- **页头 Logo 三种来源**：「自定义 Logo 图片」只在选「自定义图片」时出现。

文章区块的「文章显示样式」有三种：**卡片网格**（可再选卡片样式、标题行数、每行列数）、**紧凑列表**（日期 + 标题）、**分类分栏**（按分类各起一栏，1–3 栏）。三种样式随时互换，各自的配置都会保留。几点容易搞混的对应关系：

| 后台设置 | 真正作用的前台元素 | 不作用的地方 |
| --- | --- | --- |
| 标题最多行数 | 卡片网格的 `.article-title`：`0`＝不限（默认，不写 `--title-lines`、不挂 `article-grid--clamp`），`1/2/3`＝按行数裁切加省略号 | 紧凑列表、分类分栏 |
| 每行列数 | 卡片网格的 `.article-grid--cN`，并在「显示行数」非 0 时参与取数（行数 × 列数） | 紧凑列表、分类分栏（列数由「分类栏内容」的条目数决定，最多 3 栏） |
| 分类栏内容 | 分类分栏的 `.category-cols-wrapper` 与 `.category-col`，条目数即桌面列数 | 卡片网格、紧凑列表 |
| 显示行数 | 卡片网格取数条数（行数 × 每行列数） | 紧凑列表、分类分栏 |

切换样式时，只属于该样式的字段会自动隐藏，但已存的值不会丢；切回来仍然生效。

日期格式在「全站外观」里设置（`2024-01-01` / `2024年1月1日` / `01/01/2024` / `01-01`），作用于列表页、文章页、标签页与专题页的**完整日期**；归档页的年份、列表里的「03-04」紧凑格式和含时间的日期不受影响。留空则按站点语言显示。

页面竖向有**两条**基线，宽度刻意不同：

| 基线 | 变量 | 默认值 | 用到的地方 |
| --- | --- | --- | --- |
| 画框 | `--frame-max` / `--frame-gutter` | 1440px / `clamp(1rem, 3vw, 40px)` | 站点头部（含首页）、站点页脚 |
| 版心 | `--content-max` / `--content-gutter` | 1200px / `clamp(1rem, 3vw, 24px)` | 所有正文区块、首屏大字、区块分隔细线 |

画框比版心宽约 100px，页头页脚因此像一圈外框，正文是框内的窄栏。要调整宽度只改这四个变量，不要往单个选择器里写死宽度；首屏用的是 `--nh-hx`（画框线）与 `--nh-gx`（版心线）两个派生变量，都从上面四个值算出来。

主题只负责「看起来是什么样」；谁能申请、审核规则、通知对象、是否调用模型分析这些都在插件侧（成员管理 / 友链申请增强）。两处都有开关时，插件是总闸、主题是分闸，两处都开才生效。

## 与插件协作

NUCMA 只负责展示、布局和调用公开 Widget / Finder，不在主题内重建成员申请或友链管理业务。

| 组件 | 在主题中的作用 | 未安装时的表现 |
| --- | --- | --- |
| [成员管理](https://gitee.com/nucma/plugin-members) | 成员页、首页成员公示、`MemberApplyWidget` 申请入口、认领页、404 工牌取人、关系网数据 | 成员区块与申请入口安全降级，404 工牌回落到内置示例，不影响其他页面 |
| [官方链接管理 PluginLinks](https://www.halo.run/store/apps/app-hfbQg) | 友链数据、分组、展示和官方申请表单 | 仅官方插件存在时，主题使用原生同源申请；未启用时显示安全引导，不会另建数据存储 |
| [友链申请增强](https://gitee.com/nucma/plugin-link-submit-next) | `/links` 页官方申请表单的「获取信息」按钮 | 插件缺失或后台关闭时，表单仍按官方契约完整手动填写 |
| PluginSearchWidget | 不再需要：页头搜索改由主题自带弹层提供（覆盖文章 / 页面 / 成员 / 友情链接） | 搜索照常可用，不依赖任何插件 |
| 评论插件 | 文章和独立页面评论区 | 自动不渲染评论区 |

插件契约、验证范围与降级行为见 [插件适配矩阵](docs/plugin-compatibility.md)。

## 安装与启用

1. 从 Release 下载 `theme-nucma-<version>.zip`。
2. 在 Halo 控制台进入“外观 → 主题”，上传 ZIP 并安装。
3. 启用 NUCMA 后，进入“主题设置”完成页头、首页、文章页和页脚配置。
4. 如需成员或友链模块，先安装相关插件，再回到主题设置选择显示数量、排序和固定内容。

首次安装使用主题默认设置；以后修改过的主题设置始终以站点保存的用户配置为准。

## 推荐配置顺序

1. 在 Halo 中创建菜单、分类和文章，再到「页头与导航」选择顶部菜单。
2. 在「首页首屏」选一个版式，填这一段要用的文案、按钮与数字；换版式不会丢内容，只会换排布。
3. 在「首页区块」调整首屏之下的区块顺序。移除某个区块即可隐藏它；重新添加可恢复显示。
4. 首页文章区块默认是卡片网格（标题默认不裁、每行列数默认 3）；想按分类分栏展示时，把「文章显示样式」改成「分类分栏」，再加 1–3 个分类栏——列数跟着分类栏条目数走（加两个就是两栏），「每行列数」只管卡片网格。
5. 在「文章页与侧边栏」配置侧栏菜单与目录，在「关于页」配置站点介绍和统计项。
6. 分类或文章需要不同版式时，在 Halo 编辑界面的模板选择器中指定相应模板。
7. 需要自定义 404 时在「系统页面」里改文案与视觉；登录注册页只需决定要不要美化——站点名称、Logo、副标题、主色改好后它自动跟着变。

## 从源码构建

```bash
npm install
npm run check      # 版本、设置、SEO、H1、alt、i18n 键集合与模板契约
npm run build      # 源码检查 + 生产构建 + 生成物检查
npm run package    # 完整构建 + ZIP 打包 + ZIP 内容二次检查
npm run i18n       # 新增或删除 t('key') 后重生成 i18n 字典
```

`npm run package` 会生成完整主题包：

```text
dist/theme-nucma-<version>.zip
```
