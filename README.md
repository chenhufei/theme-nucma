# NUCMA

> 面向校园、青年组织与公共服务门户的多风格 Halo 主题，提供专题化内容模板、成员与友链展示、中英双语界面和完整的响应式阅读体验。

当前版本 **0.0.2**（Halo `>= 2.27.0`）。变更见 [CHANGELOG.md](CHANGELOG.md)，版本号规则见 [docs/versioning.md](docs/versioning.md)。

版本号规则：**大**（体系级变化，升 `MINOR`，如 0.0.x → 0.1.0）、**中 / 小**（升 `PATCH`）。已发布 tag 不删不重打。

NUCMA 的产品定位是校园、青年组织与公共服务门户。它适合校园门户、学生组织、协会、公益项目、社会实践团队和内容型机构站点：首页便于发布公告与动态，分类和文章模板可以承载专题报道，成员与友情链接则通过 Halo 插件的公开能力按需接入。

## 核心能力

### 页面与阅读体验

- 首页区块可排序，可组合文章、成员公示与友情链接；文章区块支持全部文章或 1 至 3 个分类栏。
- 提供归档、分类、标签、友链、成员、关于页、文档、瞬间、图库和错误页等页面样式。
- 文章页提供侧边栏、阅读量、标签、评论区和自动目录等可配置能力。
- 文章阅读时显示顶部进度；桌面端使用侧栏目录，移动端使用目录抽屉，并提供分享、复制链接和回到顶部操作，标准文章与专题文章均可自动提取标题。
- 正文大图支持无依赖预览，可用键盘切换、滚轮或按钮缩放、拖动查看，并自动忽略链接图片、表情和小图标。
- 文章封面和列表图片使用稳定尺寸与异步解码；列表与内容图只需写 `sizes`，由 Halo 按缩略图补 `?width=` 多档 `srcset`，不手写 `srcset`。
- 友链页支持按名称、简介或网址实时搜索，结果数量和分组数量会随筛选同步更新。
- 支持浅色、深色和跟随系统模式，统一明暗切换和滚动动画节奏。
- 桌面、平板与手机使用同一套响应式布局；手机端使用带动画的汉堡导航，并将 Halo 菜单与页头自定义链接分区显示。
- 关于页支持正文、统计、最新内容、分类、发展历程、服务入口、项目展示、成员、友链和常见问题自由排序，适配组织介绍、公共服务和专题项目展示场景。

### 成员页与关系网

- 成员卡片展示头像、学校、分组与认证状态，支持详情预览、键盘操作与 Esc 关闭；未完善资料的成员默认显示其 QQ 头像。
- 搜索支持空格分隔的多关键词、拼音与首字母，以及 `学校:`、`分组:`、`地区:`、`qq:` 字段前缀。
- 概览条汇总成员总数、分组数、学校数、近 30 天新增，地区分布、最近加入与省份地图默认收起。
- 「网格 / 关系网」可切换：关系网把头像铺在球面上，可拖动旋转、方向键微调、悬停显示姓名，点击头像打开详情；可显示学校关联连线，并配置连线阈值与「分析依据」面板；开启「减少动态效果」时停止自转。
- 「补全 QQ 链接」与认领页共用一套资料编辑：默认 QQ 头像、头像上传（浏览器内裁方形并压到 96KB 内）、学校与地区联动。

### 错误页与登录注册页

| 页面 | 能力 | 后台开关 |
| --- | --- | --- |
| 404 / 4xx / 500 / 5xx | 页面风格、标题与高亮词、状态标签、说明、按钮、插图、入场动画、织带颜色；成员工牌可按分组或指定名单取人，支持随机换人、点击翻面看 QQ 加好友链接与二维码 | 「404 页面」设置组 |
| 登录 / 注册 / 找回密码 / 退出 | 版式、主色、卡片圆角、左侧品牌面板（标语、说明、联系邮箱）、四类页面标题与副标题、登录注册互跳、返回首页、入场动画、跟随站点明暗 | 「登录注册页」设置组 |

错误页统一输出 `robots=noindex, nofollow`；登录注册页在关闭美化后回落到 Halo 默认页。工牌取不到成员时回落到主题内置示例数据，页面不会空白。

### 专题模板

分类与文章都可以在 Halo 编辑器中选择模板，无需复制页面或修改主题文件。

| 类型 | 可选模板 |
| --- | --- |
| 页面 | 关于页、认领页 |
| 分类 | 知识库列表、网格卡片、红色革命、绿色环保、蓝色马卡龙、三下乡、校园节庆、科技未来、公益志愿、传统文化、体育赛事 |
| 文章 | 信件 / 公告、杂志大图、权威发布、专题报道、沉浸阅读、人物对谈、实践手记、数据纪实、影像叙事、行动倡议 |

其中，“三下乡专题”和“实践手记”适合社会实践队伍、服务基层记录和成果报道；“信件 / 公告”模板不会自动首行缩进，适合公开信、通知和正式文稿。

### 全站视觉风格

主题设置中的“全站视觉风格”控制通用页面和组件的色彩、字体、边角与层次，内容结构保持一致：

| 风格 | 视觉方向 | 推荐场景 |
| --- | --- | --- |
| 标准门户 | 紧凑页头、居中机构首屏和矩形信息卡片 | 学校部门、协会门户、综合组织站点 |
| 青年活力 | 居中首屏、双色节奏线、胶囊控件、圆形头像和轻微错位内容节奏 | 学生组织、校园活动、青年社群 |
| 清新公益 | 居中服务首屏、导向线标题、低干扰卡片和矩形控件 | 公益项目、志愿服务、环保组织 |
| 编辑纪实 | 居中报刊式首屏、双线标题、无圆角筛选和衬线正文 | 专题报道、社会实践、机构刊物 |

用户仍可设置自定义主色；保持默认红色值时自动跟随所选风格。专题分类和专题文章拥有独立视觉表达，不会被全站预设抹平。页脚另有「默认 / 12 号 · 品牌水印 / 33 号」三套样式，随明暗模式一起切换。

### 组件设计系统

主题使用 Tailwind CSS 4 与 DaisyUI 5 作为本地构建的组件基础，不依赖公共 CDN：

- DaisyUI 统一按钮、输入框、徽章、状态提示、卡片、菜单和图片预览工具等组件状态。
- NUCMA 自有样式继续控制门户布局、内容密度、专题模板和四套视觉风格，不直接套用默认演示主题。
- DaisyUI 的颜色、圆角、边框和明暗变量映射到主题设置与自定义主色，切换视觉风格时组件会同步变化。
- 阴影使用低、中、高三档语义层级，只表达卡片悬停、浮层和模态框的空间关系；四套视觉风格分别使用柔和、克制或硬边层次，避免全站浮卡化。
- Tailwind 与 DaisyUI 仅参与构建，最终访问站点时不需要 Node.js，也不会请求外部样式资源。

### 多语言

- 界面文案以 `i18n/default.properties`（简体中文）与 `i18n/en.properties`（英文）为唯一来源，各 692 键，键集合必须一致。
- 模板里用 `#{key}` 或 `#messages.msg('key')`，前端脚本里用 `t('key')`；`templates/modules/i18n-dict.html` 由 `npm run i18n` 生成，不手改。
- 页面语言随 Halo 的站点语言设置（`#locale`）切换，`<html lang>` 同步输出。
- 新增或删除文案键后必须重跑 `npm run i18n`，否则 `npm run check` 会拦下。

## 后台配置

主题设置按页面和功能分为以下区域：

- 全局设置：全站视觉风格、自定义主色、默认明暗模式、日期格式、开发者诊断模式、自定义 CSS / JS。
- 页头设置：首页菜单、搜索、主题切换和自定义导航链接。
- 首页设置：横幅、背景轮播、首页区块排序以及区块内的内容排序。
- 文章页面：侧边栏菜单、文章元信息、评论和自动目录。
- 关于页面：区块排序、统计数据、发展历程、服务入口和常见问题。
- 独立页面：普通单页、友链页、成员页的评论开关与页面级选项。
- SEO：输出 canonical 与社交分享标签、输出页面结构化数据。
- 404 页面：页面风格、文案、按钮、成员工牌、插图、入场动画与织带颜色。
- 登录注册页：是否启用美化、版式、主色、圆角、品牌面板、四类页面文案与明暗跟随。
- 成员关系网（成员页）：默认显示网格或关系网、学校关联连线开关、连线阈值、是否显示分析依据。
- 页脚设置：页脚样式、页脚菜单栏目、「加入我们」、版权、自定义栏目与备案信息。

## 与插件协作

NUCMA 只负责展示、布局和调用公开 Widget / Finder，不在主题内重建成员申请或友链管理业务。

| 组件 | 在主题中的作用 | 未安装时的表现 |
| --- | --- | --- |
| [成员管理](https://gitee.com/xiui-cc/plugin-members) | 成员页、首页成员公示、`MemberApplyWidget` 申请入口、认领页、404 工牌取人、关系网数据 | 成员区块与申请入口安全降级，404 工牌回落到内置示例，不影响其他页面 |
| [官方链接管理 PluginLinks](https://www.halo.run/store/apps/app-hfbQg) | 友链数据、分组、展示和官方申请表单 | 仅官方插件存在时，主题使用原生同源申请；未启用时显示安全引导，不会另建数据存储 |
| [友链申请增强](https://gitee.com/xiui-cc/plugin-link-submit-next) | `/links` 页官方申请表单的「获取信息」按钮 | 插件缺失或后台关闭时，表单仍按官方契约完整手动填写 |
| PluginSearchWidget | 页头搜索入口 | 自动隐藏搜索按钮 |
| 评论插件 | 文章和独立页面评论区 | 自动不渲染评论区 |

插件契约、验证范围与降级行为见 [插件适配矩阵](docs/plugin-compatibility.md)。

## 安装与启用

1. 从 Release 下载 `theme-nucma-<version>.zip`。
2. 在 Halo 控制台进入“外观 → 主题”，上传 ZIP 并安装。
3. 启用 NUCMA 后，进入“主题设置”完成页头、首页、文章页和页脚配置。
4. 如需成员或友链模块，先安装相关插件，再回到主题设置选择显示数量、排序和固定内容。

首次安装使用主题默认设置；以后修改过的主题设置始终以站点保存的用户配置为准。

## 推荐配置顺序

1. 在 Halo 中创建菜单、分类和文章，再到“页头设置”选择顶部菜单。
2. 在“首页设置”调整首页区块顺序。移除某个区块即可隐藏它；重新添加可恢复显示。
3. 首页文章区块不配置分类栏时展示全部文章；配置分类栏后按所选分类展示，设置两个分类栏时桌面端显示两栏。
4. 在“文章页面”配置侧边栏菜单与目录，在“关于页面”配置站点介绍和统计项。
5. 分类或文章需要不同视觉风格时，在 Halo 编辑界面的模板选择器中指定相应模板。
6. 需要自定义 404 或登录页时，在对应设置组里改文案与视觉；不需要时关掉开关即回落默认页。

## 第三方依赖

主题运行依赖均随安装包本地提供，不在访问页面时请求公共 CDN：

| 依赖 | 用途 | 许可证 |
| --- | --- | --- |
| Tailwind CSS / DaisyUI | 工具样式与通用组件设计系统 | MIT |
| pinyin-pro | 成员页拼音搜索 | MIT |
| qrcode | 成员卡片与 404 工牌二维码生成 | MIT |

导航、折叠、滚动显现、计数和横幅入场均使用浏览器原生 API，不再引入通用交互或动画运行库。上述依赖仍分别遵循各自许可证，主题的 GPL-3.0 不改变第三方依赖的授权条款。成员页的拼音搜索和二维码生成按需加载；自定义 CSS、JS 和图片地址由站点管理员自行配置。

## 从源码构建

```bash
npm install
npm run check      # 版本、设置、SEO、H1、alt、i18n 键集合与模板契约
npm run build      # 源码检查 + 生产构建 + 生成物检查
npm run package    # 完整构建 + ZIP 打包 + ZIP 内容二次检查
npm run i18n       # 新增或删除 t('key') 后重生成 i18n 字典
```

`npm run package` 会生成完整主题包：

```text
dist/theme-nucma-<version>.zip
```

发布前对照 [发布验收清单](docs/release-checklist.md)，插件兼容范围看 [插件适配矩阵](docs/plugin-compatibility.md)。
