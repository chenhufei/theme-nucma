# 静态成员配置示例

由于成员插件的 API 需要登录权限，前台访客无法访问，建议使用静态成员配置。

## 配置步骤

1. 登录 Halo 后台
2. 进入「主题」→「Nucma」→「设置」
3. 找到「首页」分组
4. 找到「静态成员列表（备用方案）」配置项
5. 点击「添加」按钮，逐个添加成员信息

## 字段说明

- **displayName**（必填）：成员的显示名称
- **avatar**（可选）：成员头像的 URL
  - 可以使用 QQ 头像：`https://q1.qlogo.cn/g?b=qq&nk=QQ号&s=640`
  - 可以使用其他图片链接
  - 留空则显示默认头像
- **bio**（可选）：成员的简短介绍
- **school**（可选）：成员所属的学校或机构
  - 用于自动获取学校背景图（通过 Unsplash）
  - 留空则使用纯色背景

## 获取 QQ 头像链接

如果你有成员的 QQ 号，可以使用以下格式获取头像：

```
https://q1.qlogo.cn/g?b=qq&nk=QQ号&s=640
```

例如：
- QQ号：123456789
- 头像链接：`https://q1.qlogo.cn/g?b=qq&nk=123456789&s=640`

## 注意事项

1. **至少配置 6 个成员**，以填满首页的两行卡片（每行 3 个）
2. 如果成员不足 6 个，系统会自动重复显示以填满空间
3. 配置后保存设置，刷新前台页面即可看到效果
4. 支持所有翻牌效果和动画
5. 学校名称会用于获取背景图，建议使用完整的学校名称（如"清华大学"而不是"THU"）

## 从成员页面获取数据

如果你的成员页面（`/members`）可以正常显示，可以参考那里的成员信息来配置静态成员：

1. 访问 `/members` 页面
2. 查看成员的名称、头像、学校等信息
3. 在主题设置中手动添加这些信息

## 效果预览

配置完成后，首页成员块会显示：
- 3D 翻牌效果
- 学校背景图（自动获取）
- 每 3 秒随机翻转 1-3 张卡片
- 翻转时显示不同的成员信息
- 响应式布局，自动适配不同屏幕尺寸

## 常见问题

### Q: 为什么不能直接使用成员插件的数据？
A: 成员插件的 API 需要登录权限，前台访客无法访问。静态配置是最可靠的解决方案。

### Q: 配置后没有显示？
A: 请检查：
1. 是否保存了主题设置
2. 是否刷新了前台页面（Ctrl+F5 强制刷新）
3. 浏览器控制台是否有错误信息
4. 是否至少配置了 1 个成员

### Q: 可以配置多少个成员？
A: 没有数量限制，但建议配置 6-12 个成员以获得最佳效果。

### Q: 如何更新成员信息？
A: 在主题设置中找到对应的成员，修改信息后保存即可。

### Q: 可以删除某个成员吗？
A: 可以，在主题设置的静态成员列表中，点击成员右侧的删除按钮即可。
