# 快速修复：使用静态成员配置

## 问题总结

成员插件的 API 无法在前台使用，原因：
1. 新 API 返回 500 错误
2. 旧 API 返回的数据结构不包含成员信息
3. 所有 API 端点都需要特殊权限或配置

## 最佳解决方案：静态成员配置

### 配置步骤

1. **登录 Halo 后台**

2. **进入主题设置**
   - 点击「主题」
   - 找到「Nucma」主题
   - 点击「设置」

3. **找到静态成员配置**
   - 切换到「首页」标签
   - 滚动到「静态成员列表（备用方案）」

4. **添加成员**
   - 点击「添加」按钮
   - 填写成员信息：
     - **姓名**（必填）：例如 `清华大学表白墙`
     - **头像链接**（可选）：例如 `https://q1.qlogo.cn/g?b=qq&nk=123456789&s=640`
     - **简介**（可选）：例如 `清华大学官方表白墙`
     - **学校/机构**（可选）：例如 `清华大学`

5. **保存设置**
   - 点击页面底部的「保存」按钮

6. **刷新前台页面**
   - 按 `Ctrl+F5` 强制刷新
   - 成员块应该正常显示

### 获取 QQ 头像链接

如果你有成员的 QQ 号，可以使用以下格式：

```
https://q1.qlogo.cn/g?b=qq&nk=QQ号&s=640
```

例如：
- QQ号：`123456789`
- 头像链接：`https://q1.qlogo.cn/g?b=qq&nk=123456789&s=640`

### 从 Members 页面复制数据

如果你的 `/members` 页面可以正常显示成员：

1. 访问 `/members` 页面
2. 查看每个成员的信息
3. 在主题设置中手动添加这些信息

### 注意事项

1. **至少配置 6 个成员**以填满首页的两行卡片
2. **学校名称**用于自动获取背景图，建议使用完整名称
3. **头像链接**必须是 HTTPS 协议
4. 配置后立即生效，无需重启

### 效果

配置完成后，首页成员块会显示：
- ✅ 3D 翻牌效果
- ✅ 学校背景图（自动获取）
- ✅ 每 3 秒随机翻转 1-3 张卡片
- ✅ 响应式布局

### 常见问题

**Q: 配置后没有显示？**
A: 
1. 检查是否保存了设置
2. 强制刷新页面（Ctrl+F5）
3. 检查浏览器控制台是否有错误

**Q: 可以配置多少个成员？**
A: 没有限制，建议 6-12 个

**Q: 如何更新成员信息？**
A: 在主题设置中找到对应成员，修改后保存

**Q: 可以删除某个成员吗？**
A: 可以，点击成员右侧的删除按钮

## 为什么不使用插件 API？

1. **权限问题**：插件 API 需要特殊权限配置
2. **数据结构不匹配**：旧 API 返回的数据结构不包含分组信息
3. **稳定性问题**：新 API 返回 500 错误
4. **维护成本**：静态配置更简单、更可靠

## 总结

静态成员配置是目前最可靠的解决方案：
- ✅ 不依赖插件 API
- ✅ 不需要登录权限
- ✅ 配置简单直观
- ✅ 数据完全可控
- ✅ 支持所有功能

建议直接使用静态配置，放弃使用插件 API。
